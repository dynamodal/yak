# Decisions: app foundation

| # | Decision | Why |
| --- | --- | --- |
| F1 | Preact for the UI | React's model in about 4 KB, bundled, no build plugin |
| F2 | The app at `/`, the probe at `/probe` | The app is the product; the probe is diagnostic |
| F3 | Hash routes (`#/timer`) | No rewrite rules; works offline |
| F4 | Documents named by path-like ids, one IndexedDB database each, all synced | Several documents per space later |
| F5 | One data channel carries every document (`DocMux`) | One WebRTC connection per peer |
| F6 | Every record keyed by a fresh UUID, notes included | The merge fuzz test: two devices creating the same key lose one record |
| F7 | `scripts/serve-dist.mjs` serves the build with the real `_headers` for browser tests | `vite preview` ignores them, so CSP problems showed only after deploy |
| F8 | Automatic backups skip when nothing changed; Back up now always writes | Keeps the folder small |
| F9 | Backup files of time entries split by UTC month | Stable across devices |
| F10 | Timer and Entries count an entry on the day it started; reports cut at midnight | Day totals add up in reports |
| F11 | Report amounts use the entry's billable flag and the project's rate | As Toggl does |
| F12 | A task is a note whose `tags` contain `task`; statuses open, in-progress, done | TaskNotes default |
| F13 | Use mdbase for task fields when tasks are next changed | Owner, 2026-10-16 |
| F14 | Five top tabs, each one click: Timer, Reports, Notes, Tasks, Manage. | F25 | A device that never paired shows no sync item at all; a paired one lists its state, and only a signaling problem makes the dot amber (offline stays its own chip) | Sync is optional; "Not syncing" is not a problem |
| F26 | The backup banner shows for stale, failed and lost-access backups, with "Remind me tomorrow": hidden for 24 h in `localStorage` (`app-backup-remind-until`, this device only, never in a document). The dot stays amber while the banner is hidden | A fresh device has nothing to lose and the banner would be the first thing on every page; a reminder is per device because each device has its own folder |
| F27 | JSX conditions on strings use `{s ? <X /> : null}`, never `{s && <X />}`; a panel that holds typed input or an error gets a stable `key` | In Preact 11.0.1, a `message` going from `""` to text above `EncryptionPanel` on the Backups page remounted the panel and dropped its "Wrong passphrase." error and typed passphrase. | F28 | Public name **Yak**, "Your Activity Keeper"; Punchdeck was the codename until the rename shipped (#153) | Punchdeck read badly aloud; Yak is short, friendly and had no time-tracking or notes clash (owner, 2026-10-18, #92) |
