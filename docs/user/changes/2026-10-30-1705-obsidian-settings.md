## 2026-10-30: Obsidian plugin 0.3.0: device name and a tidier settings tab

- A new vault joins as "Obsidian (vault, desktop or mobile, four characters)", so a phone and a laptop with the same vault name no longer look alike. Vaults already joined keep their name.
- Settings › Yak Sync has a Device name field, a sync status line at the top, a Copy button for the fingerprint, and a wider Signaling server field.
- Join comes first; root folder, files and signaling server are under Advanced; the notes on where data is kept are folded away. "Forget sync code" shows only once joined.
- BRAT installs the update by itself. Nothing stored changed.
