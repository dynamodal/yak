## 2026-10-30: Obsidian plugin 0.4.0: joining by one-time code no longer stalls

- Joining a vault with a one-time code: Settings › Yak Sync now shows **The codes match** as soon as the code appears, without closing and reopening it. Before, the join waited forever after you approved it in the app.
- The notice with the code goes away once you confirm, so it no longer covers the button.
- A vault removed on the Devices page now says it was removed and how to join again, instead of "Joined".
- The plugin now needs Obsidian 1.14.5 or later; it is tested in that version and the latest one.
