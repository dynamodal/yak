## 2026-10-30: Add a task from anywhere

- Press **Alt Q** on any page, pick **New task** in the command palette, or use **New task** on the Tasks page, to add a task without leaving what you are doing.
- Type a line like `Call Bob tomorrow +Acme @phone #client !high`: the date, project, context, tag and priority are picked out for you. Chips below show them and let you change or clear each one, and choose the space.
- **Enter** adds the task and shows a notice with an Open link; **Shift+Enter** adds it and opens it; **Esc** cancels.
