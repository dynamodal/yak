## 2026-11-03: Fix gaps and overlaps from the Calendar

- A block on the Calendar opens its entry for editing; a dashed gap opens Add entry with the times filled in.
- Under the grid, each gap offers Add entry, Extend previous and Start next earlier; each overlap offers Trim first, Trim second, or (when one entry is inside the other) Split around inner, plus Edit buttons.
- Every fix shows an Undo. A running timer is never stopped by a fix.
