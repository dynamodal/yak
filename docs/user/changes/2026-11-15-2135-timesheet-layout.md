## 2026-11-15: Timesheet layout in Reports

- **Reports** has a **Table | Timesheet** switch. The Timesheet shows hours per day in tenths of an hour and a note per day, for each project or client.
- Click hours or a note to copy it. **Invoice lines** lists `date - note` with hours, with **Copy all**.
- Each day is rounded to the nearest 0.1 h and totals add the rounded days.
