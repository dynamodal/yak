# Notes and tasks

## Notes

- Notes are Markdown, kept in folders inside a space.
- Link notes with `[[Note name]]`; link to a note in another space with `[[Space:Note name]]`.
- Add tags with `#tag`. Press `Ctrl+O` to jump to a note by name.
- The editor shows the formatting as you type; it can also show the plain source.
- Every change is kept: open a note's **History** to see and restore older versions.

## Tasks

- A task is a note of its own: its front matter `tags` has `task`. **Tasks** lists those notes; type a name and **Add task** to make one. Tick one in the list or set its status in the note.
- Tasks work without Notes: switch **Notes** off in Settings › Features and keep **Tasks**. A task then opens on its own page; a link to another task opens it, a link to a plain note stays plain text until Notes is on.
- A checkbox line (`- [ ] Send invoice`) in a normal note does **not** appear in Tasks. In a task note, checkbox lines show as its progress (2 of 3). On a checkbox line, **Ctrl+Shift+Enter** turns the text into a task note and a link to it.
- Task rules are under **Task values** on **Organize**.
- **Settings › Notes** (also the gear on Notes) holds links, files, daily, weekly and monthly notes, and Mirror.

## Daily note

The command **Open today's note** (Alt+P shows all commands) opens or creates today's note.
`Ctrl+Shift+D` inserts today's date in the note you are editing.

Notes stay plain Markdown, so you can also work on them in other editors: see [Obsidian plugin](#/help/obsidian).
