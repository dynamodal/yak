# Obsidian plugin and folder mirror

Your notes are Markdown. Two ways to also use them in other editors:

## Mirror to a folder

**Mirror** (**Settings › Notes**, also the gear on Notes) keeps a folder of `.md` files in step with your notes, two ways (it needs folder access; where the browser has none, Mirror says it is not available, see [Browsers and phones](#/help/browsers)).

- One sub-folder per space. Edit a file outside Yak and the note changes, and the other way round.
- If both sides changed the same note, nothing is lost: the file's version is kept as `<name> (conflict).md`.
- Only Markdown notes are mirrored; time entries stay in the app.

## Obsidian plugin

The **Yak Sync** plugin is a device: it pairs like any other (see [Devices and sync](#/help/devices)) and keeps your notes in an Obsidian vault.
Install it with BRAT. Tick the spaces it may keep in the table on **Settings**; it keeps nothing until you do.
Version 0.2.0 gives the vault its own device keys, so it can join an account that requires them; its settings say where the keys are kept.
