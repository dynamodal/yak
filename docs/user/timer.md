# Timer and entries

## Track time

- The timer is the pill in the header, on every page. Press its round button to start at once; press it again to stop. You can add the description afterwards.
- Press the words next to the round button (**Start**, or the running description and time) to open the details: a description, **Recent** work to pick from, a project, tags and billable. **Start** (or **Update** while running) applies them. To delete an entry, running or not, use its **…** menu in the list (undo from the message, or restore it from **Recently deleted**).
- Typing a description suggests past work that matches (any order of words, small typos allowed), with its project and tags. Use the arrow keys and **Enter**, or tap one, to fill the description, project, tags and billable; then press **Enter** or **Start**. The same list shows in **Add entry** and when you edit an entry. **Esc** closes the list.
- The first **Recent** row is **Continue**: a new entry like the one that stopped last, in whichever space it was. Pick any other row to start with its description, project and tags, or, while running, to fill the running entry.
- **Alt S** (change it in Keyboard shortcuts) starts the timer and opens the details with the cursor in the description, so you can pick a past entry or type. **Esc** closes it and leaves the timer running. **Alt S** again stops the timer.
- A finished entry: **Add entry** at the top of the Time page.
- Turn the timer off in Settings › Features (**Time**). The pill, the Time tab, Reports (a part of Time) and the shortcut go; your entries are kept and keep syncing. Stop a running timer first.
- With more than one space, an entry's **…** menu has **Move to <space>**: the entry (or all entries of a repeated group) moves with its project and tags, and **Undo** puts it back. A running entry cannot be moved.
- Entries are listed by day. Open one to change its description, project, tags, billable flag, start and stop.
- The Time page has **List**, **Week** and **Reports** views; the last one you used opens next time. The space menu applies to all three.

## Projects, clients and tags

**Organize** holds them: press **Edit…** in the project or tag picker, use the command palette (**Go to Organize**), or the **Organize** section of Settings.
It also lists tags across entries, notes and tasks, and the task rules.
Deleting one hides it; entries that used it keep their data.

## Closing the page

A running timer keeps its start time, so it still counts when you come back.
On a phone, keep the page open to sync.
